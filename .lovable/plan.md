# Match the Startups Page Typography to the MU Homepage

## Scope
- Update only `src/routes/startups.tsx`.
- Preserve the hero layout, all copy, section order, media, interactions, sticky behavior, and responsive spacing.

## Changes
- Apply the homepage heading system across section headings: Inter/display family, semibold weight, tight editorial line-height, and normal letter spacing.
- Use Fraunces italic at selected emphasis moments within headings, matching the homepage’s mixed sans/serif treatment without rewriting text.
- Standardize paragraphs to the homepage body treatment: regular weight, compact responsive sizing, generous line-height, and softened white tone.
- Standardize eyebrows, labels, card headings, metrics, and founder metadata to the homepage’s mono/uppercase hierarchy.
- Carry the homepage cyan–yellow–orange accent into emphasis text and existing accent details, while keeping the approved dark page theme.
- Retain the current homepage-style section divider.

## Validation
- Run type-check and build.
- Check the startups page at desktop, tablet, and mobile widths for clipping, overflow, and readable line breaks.
